# Campus Event Manager: aivancity EcoData & Edge AI Sprint 2026

## 1. Purpose of the Application
The Campus Event Manager is a lightweight application designed to manage university activities, specifically tailored to host the **aivancity EcoData & Edge AI Sprint 2026** alongside other workshops, meetups, and student activities. It provides a complete interface to manage event catalogs, user directories, and participant registrations, while demonstrating document-oriented data modeling, NoSQL CRUD operations, and advanced MongoDB aggregation pipelines.

## 2. Technology Used
* **Frontend & Backend:** Next.js 16.4 (App Router, React Server Components, Server Actions)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Database:** MongoDB (Local instance) using the official Node.js MongoDB driver
